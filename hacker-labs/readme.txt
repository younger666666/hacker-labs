安装与配置

    下载与配置 PHPStudy
    首先，下载并安装 PHPStudy，该工具将帮助你快速配置 PHP 和 MySQL 环境。

    放置项目文件
    将 hacker-labs 文件夹放置在 PHPStudy 的 WWW 目录下，确保目录结构正确。

    初始化设置
    打开浏览器，访问 hacker/install.php 文件，按照页面提示完成初始化设置。

    访问靶场
    完成初始化后，访问 hacker-labs 目录中的应用，开始进行安全测试。

常见问题与解决方案

    SQL 注入模块无法使用
    若 SQL 注入模块无法正常运行，尝试将 PHP 版本降级至较低版本，并重启 PHPStudy 服务后再试。

    SQL 注入功能异常
    如果 SQL 注入功能无法正常工作，可能是由于 MySQL 配置限制。请按以下步骤进行调整：
        打开 MySQL 安装目录中的 my.ini 文件。
        在 [mysqld] 配置段下添加：

        secure_file_priv = ''

        请确保 secure_file_priv 后没有空格。
        保存并关闭文件，然后重启 MySQL 服务。

    警告信息（Warnings）
    在测试过程中，若出现警告信息（Warnings），可以忽略它们。警告不会影响功能的正常使用。
